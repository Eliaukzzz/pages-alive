Keep Alive 隐私政策

最后更新：2026-10-20

Keep Alive（以下简称「本扩展」）是一个浏览器扩展：它让用户指定的视频网站认为标签页始终处于前台， 从而避免切到后台时播放器降级为纯音频、切回时卡顿。

本扩展的设计原则是不接触、不收集、不传输任何用户数据。

1. 我们不收集任何数据

  • 不收集、不存储、不传输任何个人信息（姓名、邮箱、账号、位置等）。
  • 不包含任何统计、分析、广告或追踪代码。
  • 不读取、不上传你浏览的网页内容。
  • 不向任何服务器发起网络请求；扩展自身没有任何后端服务。

2. 本地保存的内容

本扩展使用 chrome.storage.sync 保存以下设置：

  • 你添加的站点列表（域名 / 链接 / 通配符）
  • 全局开关与高级选项

这些数据只存在于你的浏览器中。如果你开启了 Chrome 的同步功能，它们会随浏览器账号在你自己设备之间同步； 开发者无法访问这些数据。

3. 权限说明

权限 用途
storage 保存站点列表与开关设置
scripting 在你指定的站点动态注册内容脚本
host_permissions: <all_urls> 允许你添加任意网站；扩展只会在你列表中的站点注入脚本，其它网站不受影响

4. 远程代码

本扩展不加载、不执行任何远程代码，全部逻辑都包含在安装包内。

5. 第三方共享

不共享、不出售、不向任何第三方披露任何数据。

6. 儿童隐私

本扩展不收集任何人的数据，包括儿童。

7. 政策变更

如果本政策发生变更，我们会更新本页面顶部的日期，并在仓库中保留修改记录。

8. 联系方式

如有疑问，请通过 GitHub Issues 联系。
