# 审核测试说明（Test instructions）

> 粘贴到开发者后台「测试说明 / Notes for review」字段。

## 审核说明

```
无需登录、无需配置，安装后即可验证。

【默认状态】
安装完成后，扩展已自动把 bilibili.com 加入保护列表（可在扩展的「站点与高级设置」页确认）。
扩展没有弹窗、没有引导页、没有网络请求。

【验证步骤】
1. 打开 https://www.bilibili.com/video/BV1GJ411x7h7 ，刷新一次页面（让内容脚本生效）。
2. 点击播放，确认视频正常播放。工具栏上的扩展图标角标会显示 ON，表示当前标签页正在受保护。
3. 切换到任意其它标签页（或另一个窗口），等待约 30 秒。
4. 切回该视频页。

【预期结果】
- 播放进度条持续前进，画面连续；
- 没有黑屏、没有「缓冲中」、没有重新加载；
- 播放器不会切换成「纯音频」模式。

【可选：用控制台确认】
在该视频页打开开发者工具 Console，执行：
  document.visibilityState   // 切到后台后仍为 "visible"
  document.hidden            // false
  __keepAlive.state()        // { patched: true, realHidden: true/false, ... }

【说明】
- 扩展只对列表中的站点生效；其它网站不会注入任何脚本。
- 如果 B 站无法访问，也可以在设置页添加 youtube.com，用任意 YouTube 视频重复上述步骤。
- 扩展不修改浏览器的任何设置，只改写页面自身能读到的可见性/焦点状态。
```

## 备注

- 如果审核环境无法访问 B 站，可在设置页把 `youtube.com` 加入列表后测试。
- 首次安装会打开一次设置页，之后不会打开任何页面或弹窗。
